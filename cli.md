## `guitar-modeler-mcp`

```text
guitar-modeler-mcp exposes an MCP server and CLI for designing guitar presets: translate real-world hardware into device models and write preset files. The first supported device is the HeadRush Gigboard.

Usage:
  guitar-modeler-mcp [command]

Available Commands:
  catalog      List the models available on the device
  completion   Generate the autocompletion script for the specified shell
  decode       Decode a .rig file into its signal chain and parameter values
  design       Dial in a tone and write a .rig patch plus an HTML report
  device       List the devices the tool can target
  fx-placement Show where each effect category goes in each chain layout
  help         Help about any command
  level        Estimate a rig's output level and recommend a RigVolume
  map          Map a preset from one device to another
  mcp          Install or uninstall the MCP server in a client
  report       Render an HTML report for an existing .rig file
  search       Fuzzy-search amps, cabs, mics and effects by name or the real hardware they emulate
  serve        Run the MCP server over stdio
  setlist      Write a .setlist binding the given rig files in order
  translate    Translate real-world hardware into device models

Flags:
  -h, --help      help for guitar-modeler-mcp
  -v, --version   version for guitar-modeler-mcp

Use "guitar-modeler-mcp [command] --help" for more information about a command.
```

## `guitar-modeler-mcp design`

```text
Dial in a tone and write a .rig patch plus an HTML report

Usage:
  guitar-modeler-mcp design [flags]

Examples:
  guitar-modeler-mcp design --name "Brown Sound" --song "Van Halen - Panama" \
      --amp "Marshall JCM800" --fx '[{"type":"Tape Echo","enabled":true}]'

Flags:
      --amp string            amp: device model or real-hardware description (required)
      --amp2 string           second amp for a dual-amp parallel rig (same model = same amp on both channels)
      --cab string            cab: device model or description
      --cab2 string           cab for the second amp path
      --device string         target device (currently only gigboard is supported) (default "gigboard")
      --footswitches string   footswitch assignments as a JSON array, e.g. '[{"module":"Wham"}]'
      --fx string             effects as a JSON array
  -h, --help                  help for design
      --input-gain float      input gain in dB
      --mic string            mic: device model or description
      --mic2 string           mic for the second amp path
      --name string           rig name (default "New Rig")
      --out string            output directory (default ".")
      --output-level float    overall rig output level in dB (RigVolume, default +6 to compensate the amp master) (default 6)
      --para-delay float      delay of path B in ms (default 0)
      --para1-level float     level of path A in dB (default -6) (default -6)
      --para1-pan float       pan of path A, -100..100 (default 0)
      --para2-level float     level of path B in dB (default -6) (default -6)
      --para2-pan float       pan of path B, -100..100 (default 0)
      --path-a-fx string      effects for parallel path A as a JSON array
      --path-b-fx string      effects for parallel path B as a JSON array
      --routing string        signal-chain topology: S (serial, default), SPS-1 (serial→parallel→serial) or PS-1 (parallel from input)
      --song string           song the tone is for
      --tempo float           tempo in BPM
```

## `guitar-modeler-mcp mcp install`

```text
Writes the server entry into the selected client config. Defaults to the VS Code user profile (available in all workspaces).

Usage:
  guitar-modeler-mcp mcp install [flags]

Examples:
  guitar-modeler-mcp mcp install                  # VS Code user profile (global)
  guitar-modeler-mcp mcp install --target workspace   # .vscode/mcp.json here
  guitar-modeler-mcp mcp install --target claude      # Claude Desktop
  guitar-modeler-mcp mcp install --print              # show config without writing

Flags:
      --command string   override the server command (defaults to this executable)
  -h, --help             help for install
      --print            print the config instead of writing it
      --target string    where to install: vscode (user profile), workspace, or claude (default "vscode")
```

## `guitar-modeler-mcp map`

```text
Read a preset file for one device and write the equivalent preset for the other, translating amp, cab and effect models through their shared "inspired by" hardware.

Usage:
  guitar-modeler-mcp map <file> [flags]

Flags:
      --from string   source device (gigboard or mooer; inferred from the file extension when omitted)
  -h, --help          help for map
      --out string    output directory (default ".")
      --to string     target device (gigboard or mooer; the opposite of the source when omitted)
```
